# Подарок для Даши — квест-путешествие по нашей истории

Интерактивная игра-открытка на день рождения: 7 мини-этапов (викторины, «найди пару», загадки, пазл) по истории отношений. Каждый пройденный этап открывает фрагмент финального письма-признания. Финал — поздравление с конфетти и полное письмо.

Чистый фронтенд: React + Vite + TypeScript, без бэкенда. Работает на телефоне.

## Запуск

```bash
npm install
npm run dev
```

Открой адрес из консоли (обычно `http://localhost:5173`). Чтобы открыть с телефона в той же Wi-Fi-сети: `npm run dev -- --host` и зайди по IP компьютера.

## Как редактировать контент

Весь текст игры — в одном файле: **`src/content.ts`**. Там можно менять:

- вопросы викторин, варианты и правильные ответы (`correctIndex` — номер правильного варианта, счёт с нуля);
- загадки, ответы и подсказки;
- пары для «найди пару» (эмодзи и подписи);
- фрагменты финального письма (`letterFragments`) — по одному на этап, порядок совпадает с порядком этапов;
- тексты заставки и финала.

## Фото для пазла

Положи фото в папку `public/photos/` (создай её) с именем `confession.jpg` — или измени путь в `src/content.ts` в этапе `confession` (поле `photo`). Лучше квадратное фото. Пока фото нет, показывается иллюстрация-заглушка.

## Музыка (опционально)

Положи mp3-файл в `public/audio/theme.mp3` — появится кнопка музыки с mute. Без файла кнопка не показывается.

## Прогресс

Прогресс сохраняется в localStorage браузера. Чтобы сбросить и пройти заново — очисти данные сайта в браузере или выполни в консоли devtools:

```js
localStorage.removeItem('dasha-quest-progress-v1')
```

## Сборка и деплой

```bash
npm run build
```

Статика попадёт в `dist/` — её можно открыть локально или задеплоить:

- **Vercel**: импортируй репозиторий, всё определится автоматически.
- **GitHub Pages**: залей содержимое `dist/` в ветку `gh-pages` (база уже относительная, ничего настраивать не нужно).
